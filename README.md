# PWM Lab · 信号滤波与采样分析 v2.1.0

## 项目目标与交付

在 v2.0.0 公开产品基础上完善 ADC 配置说明、量程诊断和积分误差曲线交互。无需安装或登录，计算在访问者浏览器内运行，配置不会上传服务器。旧版本保留在各自版本文件夹。

站点注册信息位于 `.openai/hosting.json`。公开 URL 以成功发布返回的 URL 为准，发布结果另存于验证报告目录。

GitHub 镜像通过 `.github/workflows/pages.yml` 自动发布 `dist/`。推送到 `main` 后，GitHub Pages 会更新 `https://zqw222937743.github.io/pwm-lab/`；仓库地址为 `https://github.com/zqw222937743/pwm-lab`。

## UI 与产品流程

- 顶部产品栏：配置导入、保存、CSV/SVG 导出和浅色/深色主题切换。
- 左侧参数面板：信号、RC 和 ADC 分组折叠，幅值和电平定义直接显示。
- 首屏测量指标：真实/ADC 周期均值及绝对偏差，或真实/ADC 基波峰值和相位偏差。
- 中央波形工作台：整体范围包络、观察时间轴，以及原始 PWM 与 RC/ADC 的局部对比。
- 测量分析区：按测量目标切换周期积分和基波幅相；误差参考直接显示分母与公式。
- 小屏优先显示波形和结果，通过“调整参数”展开参数面板。数据表可在自身区域横向滚动。
- 无效参数保留上次有效波形，提示原因，指标降亮显示，关闭播放和导出。
- ADC 区提供单一“原理与配置指南”入口，详细解释采样、量化、限幅、误差模型和 RC 边界补偿；主参数面板保持紧凑。
- 高级 ADC 模型实时显示等效量程跨度、LSB、RC 输出范围、三倍噪声裕量和限幅样本数。
- 逐载波周期积分误差图完整显示三组图例，图例线型与曲线一致，可切换显示并在悬停时读取数值。

视觉采用冷色工程工作台：深蓝文字、清楚的层级、统一控件、浅灰工作区和白色功能面板；深色主题使用同一套语义颜色。曲线、采样点、图例和导出图表保持颜色一致。支持键盘操作、可见焦点和 200% 字体放大。

## 功能与模型

保留三种信号：SVPWM 示例、正弦占空比 PWM、固定占空比 PWM。可调幅值、占空比/调制深度、载波频率、基波频率、PWM 对齐、一阶 RC、初始输出、ADC 采样率、每载波周期点数、固定时钟偏移与周期积分方法。

### 电平定义

- SVPWM：电平尺度 `V`，调制比 `m`；组合输出 `u=V[Sa−(Sa+Sb+Sc)/3]`；可能电平 `0、±V/3、±2V/3`。目标基波峰值 `Vm/2`，电平跨度参考 `4V/3`。界面直接显示上下电平。
- 正弦占空比：高/低电平 `H、L`，`D(t)=D₀+d sin(2πft)`。目标直流 `L+(H−L)D₀`，峰值 `(H−L)d`，跨度 `H−L`。
- 固定占空比：连续周期均值 `L+(H−L)D`；观察窗口按完整载波周期数设置，没有目标低频基波。

### RC 与 ADC

RC 采用解析指数响应，`τ=1/(2πfc)`，默认窗口前预热 18τ。可指定 `y(0)`，包含启动瞬态时提示窗口分析不是稳态频响。

ADC 使用连续均匀时钟 `tₖ=(k+φ)/fADC`。采样率与每载波点数联动；固定采样率时允许非整数频率比，显示各周期实际点数。均值积分对半开窗口取真实采样均值；梯形积分使用相邻样本线性插值。

高级 ADC 模型默认关闭：增益 → 零偏 → 固定种子的独立高斯采样噪声 → 限幅 → 均匀量化。范围、零偏和噪声均采用折算到被测信号侧的等效电压；增益是接近 1 的误差系数，不是电阻分压比。页面提供理想 ADC 与 12 位 ±100 V 快速预设，并实时计算 `LSB=(Vmax−Vmin)/(2^N−1)`。本模型不描述具体 ADC 的采样保持、INL/DNL 或随机时钟抖动。

### 积分误差与边界补偿

误差 `100×(估计均值−真实均值)/参考`。参考可选信号电平跨度、目标基波峰值或当前真实周期均值绝对值。接近零时不显示相对读数误差，保留绝对偏差。

RC 补偿来自一阶 RC 方程 `u=y+τdy/dt` 的周期积分：`Icorrected=IADC+τ[yADC_interp(b)−yADC_interp(a)]`。端点来自 ADC 插值，不使用隐藏的准确模拟端点。补偿只针对当前理想一阶 RC；量化、噪声、端点插值误差、器件容差和多阶滤波均可能降低效果，因此页面明确要求比较补偿前后的实际误差。

### 基波分析

模拟信号逐事件闭式积分提取直流、正弦和余弦项；ADC 对真实样本做三参数最小二乘拟合。相位以目标正弦为 0°，ADC 偏差以实际 PWM 提取的基波为参考。ADC 样本少于 4 或采样率不超过 2 倍基波时不给出幅相估计。

残差 RMS 包含直流和当前基波之外的所有成分，不能当作某一个载波频点的纹波幅值。窗口包含瞬态或非整数载波比时，投影不等于无限时间稳态频谱。

## 配置和导出

配置在本机浏览器存储，用于恢复参数、图例和观察位置。浏览器拒绝存储时仍可使用全部计算功能。主题偏好独立保存。

可导入 v1.2.0、v2.0.0 和 v2.1.0 JSON 配置；文件 ≤16 KB；导出为 v2.1.0。CSV 包含配置、分析、完整周期结果和实际 ADC 样本；单次上限为 250000 条记录，超限明确拒绝，不静默截断。SVG 导出整体图，固化主题样式并附配置/分析元数据。

可选 WebMCP 在支持的浏览器注册 `read_pwm_analysis` 和 `set_pwm_observation`，共享界面状态。普通浏览器不受影响；不把模拟注册验证称为真实受支持浏览器验证。

## 验证与已知边界

沿用 8 组 RC 和 7 组 ADC 检查，并用独立积分验证 8 组波形/瞬态场景。网页验收检查三种信号、参数联动、基波模式、上下电平、三条积分误差曲线与图例切换、ADC 原理指南、量程/LSB/限幅诊断、配置往返、CSV/SVG 实际下载、本机恢复、主题切换、手机参数面板、播放/悬停和字体放大。1440/1024/768/390/320 px 检查无意外页面横向溢出，SVG 使用自身容器实际宽度。

本工具用于原理与采集方案比较，不直接保证实际硬件的精度或稳定性。仅提供一阶 RC；未模拟开关死区、器件压降、电机、电感、机械系统或任意波形输入。参数范围沿用 v1.2.0。详细结果见 `validation/artifacts/results.json`。
