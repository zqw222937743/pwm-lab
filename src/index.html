模型说明

周期积分与基波幅相是不同测量目标。边界补偿使用 ADC 插值端点，不保证降低误差。残差 RMS 包含基波与直流以外的成分。此工具不直接保证实际硬件精度。

ADC MODEL GUIDE

ADC 原理与配置指南

模型处理顺序

ADC 在 RC 输出上按均匀时钟采样。启用高级误差模型后，每个样本依次经过增益误差、零点偏差、独立高斯噪声、输入限幅和均匀量化。

xADC = Quantize[Clip(G·xRC + Voffset + n)]

采样率、每载波点数与时钟偏移

两者满足 fADC = N·fPWM。固定 N 适合与 PWM 同步的采样；固定采样率适合独立 ADC 时钟，此时每个载波周期的点数可能不同。时钟偏移表示整个 ADC 时钟相对 PWM 边界的固定位置，单位是一个 ADC 采样间隔的百分比，不是随机抖动。设计时应扫过 0–100%，检查最差相位。

周期积分方法

“周期内采样点均值”复现固件中对每个载波周期 N 点直接求平均的算法。“边界插值＋梯形积分”先用相邻样本线性插值载波周期边界，再对插值波形积分；它通常更适合非整数点数或异步采样，但不等于真实连续波形积分。

量程、位数和量化

输入上下限均为折算到被测信号侧的等效量程，不应直接填写 ADC 芯片引脚的 0–3.3 V。量程应覆盖 RC 输出、残余开关纹波、零偏与噪声裕量。

LSB = (Vmax − Vmin) / (2Nbits − 1)

缩小量程会改善量化分辨率，但可能产生限幅。标称位数不等于有效位数，额外噪声可以近似反映 ENOB 下降。

增益、零偏与噪声

增益误差系数的理想值为 1；高 0.5% 填 1.005，低 0.5% 填 0.995。它不是前端电阻分压比。零点偏差和噪声 RMS 也应折算到被测信号侧。页面噪声为固定随机种子的独立高斯噪声，不包含开关尖峰、带限噪声或时钟抖动。

RC 边界补偿原理

一阶 RC 满足 u = y + τ·dy/dt。在载波周期 [a,b] 上积分后：

∫u dt = ∫y dt + τ[y(b) − y(a)]

因此可在 ADC 对 RC 输出的积分结果上增加边界项：

Icorrected = IADC + τ[yinterp(b) − yinterp(a)]

页面只使用 ADC 相邻样本插值得到的边界值，不偷用仿真的准确端点。补偿成立的前提是前端可近似为已知时间常数的一阶 RC；量化、噪声、端点插值误差、器件容差、多阶滤波和采样不同步都可能使补偿变差，所以必须比较补偿前后误差，不能默认补偿一定更准。

推荐配置步骤

  1. 先关闭高级误差模型，只分析 RC、采样率和采样相位。
  2. 选择与固件一致的积分方法，并扫过采样时钟偏移。
  3. 开启高级模型，填写折算到被测侧的实际量程和 ADC 位数。
  4. 再逐项加入增益误差、零偏和实测噪声 RMS。
  5. 确认限幅样本数为 0，并比较 ADC 离散积分与边界补偿曲线。
